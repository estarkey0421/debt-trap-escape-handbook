# Corrections & Contributions

Lending law changes every legislative session. **A stale citation in this project can hurt someone**, so corrections outrank everything, including pride.

**Found a stale or wrong citation?** Open an Issue with:
1. The state and the current claim in the document
2. What changed (link to the statute on the legislature's .gov site, a regulator notice, or a news report of the bill)
3. The date it took effect

Confirmed corrections are applied with a changelog entry, and the version number bumps.

**Want to add value?** The most useful contributions, in order:
- Verifying the remaining ◐ entries against primary sources (see the Cite column in Part 4)
- State regulator phone numbers, individually verified by calling them
- Translations (Spanish first) — CC BY-SA lets you translate freely; open an issue so it can be linked
- Reports from the field: which lenders folded, what collectors said, how long silence took

**Ground rules:** keep the fraud disclaimer and the Verification Protocol intact in any fork or adaptation — they are load-bearing. Never remove the "one real danger" court-summons warning.
